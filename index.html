    窗口与记忆Window and memory

    一个模型支持长上下文。只凭这个数字，能否断言它下次对话仍记得你？A model advertises a large context window. Does that alone establish that it remembers you in the next conversation?

    1. A：可以，窗口越大记得越久。A: Yes; a larger window means longer lasting memory.
    2. B：不能，还要知道下次实际传入什么，以及是否另有保存机制。B: No; inspect the next request and any separate persistence mechanism.
    作答后看理由与下一步After answering: reasoning and next steps

    选 B。上下文容量、实际输入和跨次保存是不同问题。A 把容量变成了持久记忆承诺，缺少依据。先画出一次请求带入的内容，再讨论保存。Choose B. Capacity, actual request content and persistence are separate questions. A turns capacity into an unsupported memory promise. Map one request before discussing what is saved.

    相似与证据Similarity and evidence

    检索排第一的段落和问题很像，但只谈去年。能直接拿它证明今年的价格吗？The top retrieved passage resembles the question but describes last year. Does it establish this year’s price?

    1. A：不能，相关不代表支持当前时间和口径。A: No; relevance does not establish the current time/scope.
    2. B：可以，排名第一就是答案。B: Yes; the first rank is the answer.
    作答后看理由与下一步After answering: reasoning and next steps

    选 A。检索排序只提供候选材料；仍要检查对象、日期、档位和原句是否支持结论。B 把排序当成了事实核验。找不到当前证据时写未知。Choose A. Ranking supplies candidates; check object, date, tier and support in the passage. B mistakes order for verification. Keep the current fact unknown without evidence.

    输入缺信息Missing input

    空白单价A blank price

    扫描订单里 003 的单价为空。表格转换时应该怎样记录？The scan has a blank price for item 003. How should conversion record it?

    1. A：填 0，让合计能算出来。A: Fill zero so a total can be calculated.
    2. B：留空，标缺失，并保留页与行位置。B: Keep it blank, mark it missing and retain page/row evidence.
    作答后看理由与下一步After answering: reasoning and next steps

    选 B。缺失值不是零。A 虚构了价格，也会把部分小计伪装成完整总额。先确认是原件未提供还是识别漏掉，再决定能否补录。Choose B. Missing is not zero. A invents a price and can disguise a partial sum as a total. Establish whether the original is blank or extraction omitted a value before adding anything.

    日期歧义An ambiguous date

    两份订单都写 03/11/2026，没给地区约定。你能直接改成 2026-11-03 吗？Two orders say 03/11/2026 without a locale. Can you normalize it directly to 2026-11-03?

    1. A：能，按自己电脑的设置。A: Yes; use the computer’s locale.
    2. B：不能，保留原值并请求口径，暂列异常。B: No; retain the raw value, ask for the convention and quarantine it.
    作答后看理由与下一步After answering: reasoning and next steps

    选 B。同一字符可以表示不同日期。电脑设置不能替代数据来源的定义。只有获得明确口径后才转换，并记录规则与受影响的行。Choose B. The same string can denote different dates. Local computer settings do not define source data. Normalize only after the convention is established, recording the rule and affected rows.

    结果缺验证Unchecked output

    有角标就够了吗Is a source marker enough?

    摘要有引用链接，原文却写“预览”，摘要写“全部上线”。先改什么？A summary has a citation, but the source says preview while the summary says available to everyone. What needs correction?

    1. A：加更多角标就能保留原结论。A: Keep the claim and add more citations.
    2. B：把结论收回原文支持的范围，再查日期与对象。B: Limit the claim to source support, then check date and eligible users.
    作答后看理由与下一步After answering: reasoning and next steps

    选 B。链接存在不证明它支持这句话。A 增加数量却没有修复含义。逐条对照原句，保留预览、推出范围和核验日期；证据不足时撤回结论。Choose B. A working URL does not establish support for a sentence. A adds quantity without fixing meaning. Check each passage and retain preview status, availability scope and check date; withdraw unsupported claims.

    • 怎么验证 AI 的输出Check support, scope and numbers
    • 审阅两版文档的冲突Review conflicting document versions

    提议还是决定Proposal or decision

    Jo 说“建议加字幕，但本周无法负责”。纪要把任务分给 Jo。是否合格？Jo suggests subtitles but says they cannot own them this week. Notes assign the work to Jo. Is that acceptable?

    1. A：不合格，提议与接受任务不同，应把负责人留待确认。A: No; proposing differs from accepting ownership. Keep the owner unresolved.
    2. B：合格，谁提议就由谁负责。B: Yes; whoever suggests it owns it.
    作答后看理由与下一步After answering: reasoning and next steps

    选 A。原话没有接受分派，而且明确说明无法负责。B 编造了责任规则。回听对应片段，把状态改回提议，负责人和期限分别确认。Choose A. The speaker did not accept assignment and explicitly cannot own it. B invents an assignment rule. Replay the passage, restore proposal status, and confirm owner and deadline separately.
