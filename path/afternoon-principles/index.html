第 3 题 · 参考回答Question 3 · Reference answer

生成目标不保证每个断言有事实依据；更多上下文还会增加处理量和缓存占用。应区分输入长度、输出长度与运行方式，不把长窗口理解成可靠性保证。The generation objective does not guarantee factual support for every claim. More context adds computation and cache use. Distinguish input length, output length and runtime; a long window does not guarantee reliability.
