选型决策者路线The Decision-Maker's Route

约 50 分钟about 50 minutes

替团队做选择的人：不学原理，只学决策要看的维度——成本、锁定、合规、评测口径。For whoever chooses for the team: skip the mechanics, learn the dimensions a decision turns on — cost, lock-in, compliance, and how scores are produced.

按这个顺序读Read in this order
  1. AI 产品 vs AI 模型Product vs Model
  2. 开源模型Open-weight Model
  3. 开放权重Open Weights
  4. 许可证License
  5. 成本Cost
  6. 自托管成本Self-hosting Cost
  7. 供应商锁定Vendor Lock-in
  8. 退出成本Exit Cost
  9. 数据不出网Data Sovereignty
  10. 数据驻留Data Residency
  11. 隐私与合规Privacy & Compliance
  12. 生成式 AI 合规义务Generative AI Compliance Duties
  13. 基准测试Benchmark
  14. 模型评测的局限Evaluation Limits
学完自测Checkpoint
  1. 用三个维度对比「调 API」与「自己部署」的总成本
  2. 说出更换模型供应商之前必须核实的三件事
  3. 看一份供应商评测报告，判断哪些分数可以直接采信、哪些要打问号
  1. Compare API usage against self-hosting on three cost dimensions
  2. Name three things to verify before switching model vendors
  3. Read a vendor's evaluation report and say which scores stand up and which need a question mark
