半小时入门The Half-Hour Primer

入门Starter没基础也能读，先建立概念No background needed: build the concepts first

约 30 分钟about 30 minutes

先读十个常用概念，再做十道自测。目标是分清模型、产品与能力边界，不需要记住全部名词。Read ten common concepts, then try ten questions. Aim to distinguish models, products and limits without memorizing the whole glossary.

按这个顺序读Read in this order
  1. 人工智能Artificial Intelligence, AI
  2. 机器学习Machine Learning, ML
  3. 大模型 / 大语言模型Large Language Model, LLM
  4. 提示词Prompt
  5. TokenToken
  6. 上下文窗口Context Window
  7. AI 产品 vs AI 模型Product vs Model
  8. 生成式 AIGenerative AI
  9. AI Agent 与聊天机器人的区别Agent vs Chatbot
  10. 能力边界Capability Boundary
学完自测Checkpoint
  1. 向外行解释：大模型是怎么「学会」的，为什么按 Token 计费
  2. 说清「AI 产品」和「AI 模型」的区别，各举一个例子
  3. 说出大模型至少一件明确做不到的事
  4. 机器学习、深度学习、大模型三者是什么关系？
  5. 把上下文窗口从 8k 扩到 128k，为什么成本和延迟通常会上升？
  6. 生成式 AI 与只做分类的模型，输出目标有什么根本不同？
  7. AI Agent 与聊天机器人最大的区别是什么？各举一个任务。
  8. 为什么「回答很流畅」不能当作正确性的证据？
  9. 同一句提示，为什么两次输出可能不同？
  10. 拿到一个 AI 产品页，先用哪三个问题判断它是否适合？
  1. Explain to a newcomer how a large model learned, and why billing counts tokens
  2. Tell apart an AI product from an AI model, with one example each
  3. Name at least one thing a large model plainly cannot do
  4. How do machine learning, deep learning and large models relate?
  5. Why do cost and latency usually rise when context grows from 8k to 128k?
  6. What fundamentally differs between generative AI and a classifier?
  7. What is the biggest difference between an AI agent and a chatbot? Give one task for each.
  8. Why is fluent wording not evidence of correctness?
  9. Why can the same prompt produce different outputs twice?
  10. Which three questions should you ask first about an AI product page?

先试着回答，再展开参考答案。答不上来的地方，可从上方步骤返回对应词条。参考回答是核对要点，不要求逐字复述。Try answering before opening the reference. Revisit the relevant step above if needed. These answers highlight key ideas; you do not need to repeat the wording.

第 1 题 · 参考回答Question 1 · Reference answer

训练用样本调整模型参数，推理时依据输入生成输出。Token 是处理文本的单位；服务商通常分别统计输入与输出的用量，具体收费规则看产品说明。Training adjusts model parameters from examples; inference generates output from an input. Tokens are text-processing units. Providers commonly count input and output usage separately; the product defines billing.

回看这一题的概念Revisit this concept

第 2 题 · 参考回答Question 2 · Reference answer

模型是生成或处理内容的核心；产品还包括界面、检索、存储和权限。例如，一个聊天网站是产品，它接入的语言模型是其中一个部件。A model generates or processes content. A product also has an interface, retrieval, storage and permissions. A chat website is a product; its language model is one component.

回看这一题的概念Revisit this concept

第 3 题 · 参考回答Question 3 · Reference answer

没有可靠资料或相应工具时，模型不能保证给出最新事实，也不能仅凭流畅的回答证明内容正确。可举一个需要核对原始出处的例子。Without reliable sources or suitable tools, a model cannot guarantee current facts. Fluent wording does not prove correctness. Give one example that needs an original-source check.

回看这一题的概念Revisit this concept

第 4 题 · 参考回答Question 4 · Reference answer

机器学习是让模型从数据中找规律的总称；深度学习是用多层神经网络做这件事；大模型通常指参数规模很大、以 Transformer 为主的深度学习模型。大模型不是机器学习的全部，也不等于某个产品。Machine learning is the broad approach of learning patterns from data; deep learning uses multilayer neural networks; large models are usually very large Transformer-based deep networks. A large model is not all of machine learning, nor a product.

回看这一题的概念Revisit this concept

第 5 题 · 参考回答Question 5 · Reference answer

模型要处理更多 token，注意力和缓存的计算/存储随长度增长；服务端还要为更长请求预留显存与带宽。窗口变大只说明能放更多输入，不代表每个位置都同样被有效利用。The model processes more tokens, and attention plus cache computation and storage grow with length; the server also reserves more memory and bandwidth. A larger window only means more input fits, not that every position is used equally well.

回看这一题的概念Revisit this concept

第 6 题 · 参考回答Question 6 · Reference answer

分类模型输出有限标签上的概率；生成式模型输出 token 序列的分布，需要逐词采样。后者能写新内容，也带来事实不一致和不可复现的风险。A classifier outputs probabilities over a finite label set; a generative model outputs a distribution over token sequences and samples token by token. The latter can write new content, and brings factual inconsistency and non-reproducibility.

回看这一题的概念Revisit this concept

第 7 题 · 参考回答Question 7 · Reference answer

聊天机器人主要生成回答；Agent 还会规划步骤、调用工具、读取结果并继续行动。比如问答是聊天；查库存、改工单、发邮件则是 Agent 任务。是否自主调用工具与承担副作用，是分界线。A chatbot mainly generates replies; an agent also plans steps, calls tools, reads results and keeps acting. Q&amp;A is chat; checking inventory, editing a ticket or sending mail is an agent task. Tool use and side effects are the dividing line.

回看这一题的概念Revisit this concept

第 8 题 · 参考回答Question 8 · Reference answer

流畅只说明语言模型在预测下一个 token 上表现好，不保证每个断言有来源。核对要回到原始资料，尤其是数字、日期、引文和承诺。Fluency only shows the model is good at predicting the next token; it does not guarantee a source for every claim. Check original material, especially numbers, dates, quotations and commitments.

回看这一题的概念Revisit this concept

第 9 题 · 参考回答Question 9 · Reference answer

生成时通常按概率采样，温度、随机种子和服务端批处理都会影响结果；模型版本或上下文变化也会改变输出。需要可复现时，要固定设置并记录版本。Generation usually samples from probabilities; temperature, random seeds and server batching all affect the result, as do model version and context changes. For reproducibility, pin settings and record the version.

回看这一题的概念Revisit this concept

第 10 题 · 参考回答Question 10 · Reference answer

一问任务与验收标准是否能被它覆盖；二问数据去哪里、是否留存或跨境；三问总成本、许可和退出方式。先答这三题，再看演示效果。First, can it cover the task and acceptance criteria; second, where data goes and whether it is retained or transferred; third, total cost, licence and exit. Answer these before judging demos.
