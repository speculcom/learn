  2. 说清「AI 产品」和「AI 模型」的区别，各举一个例子
  3. 说出大模型至少一件明确做不到的事

  3. Name at least one thing a large model plainly cannot do

第 1 题 · 参考回答Question 1 · Reference answer

训练用样本调整模型参数，推理时依据输入生成输出。Token 是处理文本的单位；服务商通常分别统计输入与输出的用量，具体收费规则看产品说明。Training adjusts model parameters from examples; inference generates output from an input. Tokens are text-processing units. Providers commonly count input and output usage separately; the product defines billing.

第 2 题 · 参考回答Question 2 · Reference answer

模型是生成或处理内容的核心；产品还包括界面、检索、存储和权限。例如，一个聊天网站是产品，它接入的语言模型是其中一个部件。A model generates or processes content. A product also has an interface, retrieval, storage and permissions. A chat website is a product; its language model is one component.

第 3 题 · 参考回答Question 3 · Reference answer

没有可靠资料或相应工具时，模型不能保证给出最新事实，也不能仅凭流畅的回答证明内容正确。可举一个需要核对原始出处的例子。Without reliable sources or suitable tools, a model cannot guarantee current facts. Fluent wording does not prove correctness. Give one example that needs an original-source check.
