图像 / 视频 / 音频创作者路线The Image / Video / Audio Creator's Route

约 40 分钟about 40 minutes

沿文字、图像、视频与声音的生成环节，检查常见失败、素材来源与发布条件。目标是能列出验收项。Study generation across text, image, video and sound, including failures, provenance and publication conditions. Aim to define acceptance checks.

学完自测Checkpoint
  1. 说清文生图 / 视频生成 / 语音合成各自的一条主要失败模式
  2. 拿到一个生成工具，能先核对商用许可与训练数据来源，再看效果
  3. 知道发布 AI 生成内容时的标识义务，以及哪些素材不能直接商用
  1. Name one main failure mode for text-to-image, video generation and speech synthesis each
  2. Given a generation tool, check commercial licensing and training-data provenance before judging output
  3. Know the labelling duties for publishing AI-generated content and which assets cannot be used commercially

第 1 题 · 参考回答Question 1 · Reference answer

图像可检查局部结构与文字；视频检查跨帧连续性；语音检查读音、节奏与身份授权。列出检查项，再看生成结果，不只凭整体观感判断。Check local structure and text in images, continuity across video frames, and pronunciation, pacing and identity authorization in speech. Use explicit checks rather than overall polish.

第 2 题 · 参考回答Question 2 · Reference answer

先读当前产品、档位和素材类型对应的条款；分别查输入素材能否使用、输出能否按计划发布、输入是否用于训练。允许发布不等于获得所有第三方权利。Read terms for the actual product, tier and asset type. Check input rights, intended output use and training use separately. Permission to publish does not clear every third-party right.

第 3 题 · 参考回答Question 3 · Reference answer

按发布地区和平台的现行规则核对标识；字体、音乐、人物形象和参考图分别记录来源与许可。无法确认的素材先替换或暂不发布。Check current labeling rules for the publication region and platform. Record sources and permissions for fonts, music, likenesses and references separately. Replace or withhold unresolved assets.
