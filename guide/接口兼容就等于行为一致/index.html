接口兼容就等于行为一致A Compatible API Means Identical Behaviour

微型指南 · 约 5 分钟Guide · about 5 min · 引用核验 2026-11-03（仅引用链接与日期） · refs checked 2026-11-03 (reference links and dates only)

兼容保证的是请求与响应的形状。Compatibility guarantees the shape of requests and responses, nothing more.

只要接口兼容 OpenAI，换过去效果就一样。If the API is OpenAI-compatible, switching over gives the same behaviour.

兼容通常指某些请求与响应约定。支持范围、默认参数、流式、工具调用和错误处理仍需逐项核对。接口名称相同不代表产品行为或输出质量相同。Compatibility typically concerns specified request/response conventions. Check supported scope, defaults, streaming, tools and errors individually. Shared interface names do not establish equal behavior or output quality.
