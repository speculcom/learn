多模态模型怎么验收How to Acceptance-Test a Multimodal Model

微型指南 · 约 8 分钟Guide · about 8 min · 引用核验 2026-11-19（仅引用链接与日期） · refs checked 2026-11-19 (reference links and dates only)

看图答得漂亮不等于能用；验收要把「看见」「看懂」「据此做事」分开测。A pretty answer about an image does not mean it works. Acceptance testing separates seeing, understanding and acting on it.

怎么做How to

建三组题：纯识别（OCR、物体、图表读数）、关系推理（比较、因果、空间）、任务执行（按图改代码、填表、导航）。

每题保留原图与标准答案，要求模型引用图上坐标或区域；不能引用就判「蒙对」。

加入对抗样本：模糊、旋转、遮挡、错别字、图表误导；看它是否承认看不见。

分开测「描述」与「决策」：描述对但行动错，说明视觉到动作的链路没打通。

记录 token 成本：图像 token 化很贵，长图与多图会显著推高单价。

用同一组题对比至少一个基线模型；没有基线就没有「好」。

Build three sets: pure recognition (OCR, objects, chart reading), relational reasoning (comparison, cause, space), and task execution (edit code from an image, fill a form, navigate).

Keep the original image and the reference answer for every item; require the model to cite coordinates or regions. If it cannot, count it as a lucky guess.

Add adversarial samples: blur, rotation, occlusion, typos, misleading charts; see whether it admits it cannot see.

Test description and decision separately: a correct description with a wrong action means the vision-to-action path is not connected.

Record token cost: image tokenisation is expensive, and long or multiple images raise the unit price sharply.

Compare against at least one baseline on the same set; without a baseline there is no “good”.

例子与判断Example and interpretation

以下是教学情境，不是本站运行或实测记录。A teaching scenario, not a measured or executed site test.

找一张带小字与图例的财务报表截图，要求模型读出三个数字并给出坐标区域；再把图旋转 15 度、局部遮挡，看它是否承认读不清。两次都过，才算具备可用的图表理解。Give the model a financial table screenshot with small text and a legend, ask for three numbers plus their bounding regions. Rotate the image 15 degrees and occlude part of it; a usable chart reader must say what it cannot see. Pass both to qualify.

做完例子后怎么检查How to check your practice

先用自己的话解释上面的判断，再检查输入条件，最后回原文验证。说不清原因时回概念；缺日期、字段或权限时补输入；结论无出处时先撤回结论。Explain the example in your own words, inspect input constraints, then verify against the source. Revisit concepts if you cannot explain why; supply missing dates, fields or permissions; withdraw unsupported conclusions.
