The Everyday User's Route

StarterNo background needed: build the concepts first

about 30 minutes

Start from everyday use: learn capabilities and errors, then check sources, privacy and publication requirements. No programming background required.

Read in this order
  1. Artificial Intelligence, AI
  2. Generative AI
  3. Prompt
  4. AI Search
  5. Hallucination
  6. Multimodal
  7. Privacy & Compliance
  8. Watermarks and Content Credentials
Checkpoint
  1. Explain why an AI answer can be wrong and know at least two ways to check it
  2. Given AI-generated text or images, identify which claims need human verification
  3. Know what not to paste into a public chat tool, and how to use temporary chat or turn off training
  4. What is the biggest difference between AI search and ordinary search?
  5. How do multimodal models fail differently on images and text?
  6. What can watermarking and content credentials prove, and what can they not?
  7. Is a longer prompt always better?
  8. Why should you not paste your ID or a customer list into a public chat?
  9. How do you tell whether a “generative AI” claim is just a template?
  10. What three checks should an AI-generated image pass before publication?

Try answering before opening the reference. Revisit the relevant step above if needed. These answers highlight key ideas; you do not need to repeat the wording.

Question 1 · Reference answer

Models may invent unsupported details. Check each claim against the original material and cross-check key claims with an independent reliable source. Repeating the same model response is not independent evidence.

Revisit this concept

Question 2 · Reference answer

Check names, dates, amounts, quotations, image labels and external commitments. Remove or label unverified details; natural-looking output is not sufficient for publication.

Revisit this concept

Question 3 · Reference answer

Separate public material from identity, customer and internal data. Read the product’s current data-use, retention and deletion terms. Temporary chats and training switches are not blanket zero-retention guarantees.

Revisit this concept

Question 4 · Reference answer

Ordinary search returns a list of sources; AI search synthesises an answer with a few citations. Synthesis is faster but can misread sources or omit counterexamples; check key claims on the original page.

Revisit this concept

Question 5 · Reference answer

Text can fail on negation, conditions and long-range reference; images on small text, tables, occlusion and spatial relations. Test each modality separately; a fluent description is not item-by-item verification.

Revisit this concept

Question 6 · Reference answer

They can record provenance or mark generated content, helping platforms and readers; they cannot prove truth, correctness or that the file was not re-edited. Watermarks can be cropped, credentials can be missing.

Revisit this concept

Question 7 · Reference answer

No. A long prompt that mixes goal, material and constraints makes priorities harder to find; write the task and acceptance first, then add necessary context. Length is not quality.

Revisit this concept

Question 8 · Reference answer

Public products may retain chats, train on them or have them reviewed; once uploaded, withdrawal is hard. Mask the data, use temporary chat or a local tool, and check current terms and deletion.

Revisit this concept

Question 9 · Reference answer

See whether it handles unseen input, gives checkable sources and admits uncertainty. A product that only assembles fixed options and cannot explain provenance is closer to a template than a generative model.

Revisit this concept

Question 10 · Reference answer

Check text and numbers in the image, rights for people/brands/landmarks, and whether AI-generation labelling is required. Record all three; replace unresolved assets.
