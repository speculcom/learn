The Writer's Route

StarterNo background needed: build the concepts first

about 40 minutes

Study limitations and checks for research, writing and citations. Then practice on a short source passage rather than memorizing prompting tips.

Read in this order

  8. Temperature

Checkpoint
  1. Name two causes of hallucination, each with an example from a writing scenario
  2. Replace trusting AI-provided citations on faith with retrieval plus your own verification
  3. Given a passage of AI text, say which parts require human review and what to check
  4. How does a knowledge cutoff affect writing about a “latest policy”?
  5. Does higher temperature improve style or factual reliability?
  6. What should a writer do when system and user prompts conflict?
  7. Why can filling the context with material make the key sentence harder to find?
  8. Why is a working citation link still not enough to quote?
  9. Which edits can turn a rewrite into misrepresentation?
  10. List four checks before publishing an AI-written passage.

Try answering before opening the reference. Revisit the relevant step above if needed. These answers highlight key ideas; you do not need to repeat the wording.

Question 1 · Reference answer

Missing sources, ambiguity and generation randomness can affect output. For an event notice, provide confirmed time and venue and require missing facts to remain unknown.

Revisit this concept

Question 2 · Reference answer

Open the original page to check author, date and wording, then confirm that it supports the claim. A reachable URL is not enough. Do not treat unverified citations as evidence.

Revisit this concept

Question 3 · Reference answer

Verify names, numbers, quotations, factual claims and external commitments. Seek reliable support for specialist judgments. Check preservation of meaning, not grammar alone.

Revisit this concept

Question 4 · Reference answer

The model does not know changes after the cutoff and may fill them with older versions. Check official dates first; use retrieval or human input for post-cutoff facts, not model memory.

Revisit this concept

Question 5 · Reference answer

Temperature changes sampling randomness and makes wording more varied; it adds no factual support and may increase instability. Lower randomness for factual passages and check sources.

Revisit this concept

Question 6 · Reference answer

The system prompt defines the role and non-negotiable rules; the user prompt can only ask within them. The system constraint wins; if the business needs different rules, change configuration rather than bypassing it.

Revisit this concept

Question 7 · Reference answer

In a long context, information competes for attention and the key sentence can be buried; chunking, ordering and duplication also matter. State the task and retrieval scope, then ask for passage-level citations instead of one giant dump.

Revisit this concept

Question 8 · Reference answer

A reachable link only proves the page exists, not the author, date, wording or that it supports your sentence. Open the page and check the exact passage and context; delete or mark unknown if absent.

Revisit this concept

Question 9 · Reference answer

Removing qualifications, turning possibility into certainty, presenting someone’s view as fact, or changing the referent all alter meaning. Rewrites must preserve scope and attribution; check key sentences against the original.

Revisit this concept

Question 10 · Reference answer

Check names/numbers/dates, citations and sources, whether meaning changed, and external commitments plus required labelling. Publish only after all four; remove or mark unknown what cannot be confirmed.
