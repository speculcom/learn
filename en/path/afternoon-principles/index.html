Question 1 · Reference answer

For an autoregressive language model: tokenize, embed, apply layers with attention, obtain a next-token distribution, select a token and repeat. This sketch does not describe every Transformer task.

Revisit this concept

Question 2 · Reference answer

A common chat-model recipe uses pretraining, supervised fine-tuning and preference optimization: general patterns, task/response formats, and preferences or constraints. Actual recipes can merge, repeat or omit stages.

Revisit this concept

Question 3 · Reference answer

The generation objective does not guarantee factual support for every claim. More context adds computation and cache use. Distinguish input length, output length and runtime; a long window does not guarantee reliability.

Revisit this concept

Question 4 · Reference answer

Standard self-attention compares every token with every other token; doubling length roughly squares the number of pairs, while the KV cache grows linearly. Sparse, chunked or linear attention trades approximation for implementation complexity.

Revisit this concept

Question 5 · Reference answer

Training gives nearby representations to words that appear in similar contexts, so similarity reflects usage rather than dictionary meaning. Polysemy can still collide; vector distance alone does not settle meaning.

Revisit this concept

Question 6 · Reference answer

The model is trained to predict the next token given prior text; the new token is fed back before the next step. Whole-passage output needs a different non-autoregressive model, with different quality and speed trade-offs.

Revisit this concept

Question 7 · Reference answer

Given data, parameters and compute, they predict loss trends and diminishing returns; they do not guarantee task quality, factual correctness or the ceiling set by data quality. They are extrapolation tools, not product promises.

Revisit this concept

Question 8 · Reference answer

Pretraining learns general patterns from large unlabelled text; fine-tuning adjusts tasks and response formats with smaller, high-quality labelled or instruction data. Fine-tuning cannot replace pretraining or guarantee updated facts.

Revisit this concept

Question 9 · Reference answer

No. The window only sets how many tokens fit; effective use depends on attention, position extrapolation, where evidence sits and training length. Longer windows also add cost and latency.

Revisit this concept

Question 10 · Reference answer

The generation objective optimises next-token likelihood, not truth; so the model fills gaps without evidence. Check: trace each key claim to original material, and mark unknown if absent.
