The Office Route

StarterNo background needed: build the concepts first

about 45 minutes

Move from using AI as a search box to wiring it into documents, spreadsheets, meetings and email. Learn the limits first, then rehearse one complete workflow per scenario.

Read in this order
  1. Agent vs Chatbot
  2. Prompt
  3. Structured Output
  4. Context Window
  5. Hallucination
  6. Human Review Queue
  7. Guardrails
  8. License
  9. Data Residency
  10. How to take meeting notes with AI
  11. How to build a slide deck with AI
  12. How to analyse a spreadsheet with AI
  13. How to draft email and schedule with AI
Checkpoint
  1. Given a meeting transcript, mark which sentences must be checked against the transcript and which can go straight into minutes
  2. Explain which steps AI owns and which a human owns in a deck or spreadsheet task
  3. Decide whether office data can go into a cloud model based on residency and licensing, not on “everyone does it”
  4. What must be marked “to confirm” in meeting minutes?
  5. For AI-assisted slides, start with the outline or the template?
  6. What does AI most often get wrong in table analysis?
  7. Before sending an AI-drafted email, what three checks are mandatory?
  8. Why is a “risk list” not enough for contract review?
  9. In localisation, what should and should not be translated?
  10. What is the minimum de-identification rule before giving customer data to AI for cleaning?

Try answering before opening the reference. Revisit the relevant step above if needed. These answers highlight key ideas; you do not need to repeat the wording.

Question 1 · Reference answer

Numbers, commitments, names, dates and ownership must trace to the transcript; summaries can be generated but must still point back to a line.

Revisit this concept

Question 2 · Reference answer

AI owns structure, first drafts, variants and checklists; the human owns goals, trade-offs, fact-checking and sending.

Revisit this concept

Question 3 · Reference answer

Check data class, contract/compliance rules, retention and cross-border transfer. If unclear, use a local model, mask the data or do not upload.

Revisit this concept

Question 4 · Reference answer

Items without an owner, deadline, numeric definition or decision basis. Minutes are not transcripts; writing a guess as a conclusion is more dangerous than omitting it.

Revisit this concept

Question 5 · Reference answer

Fix the outline and the point of each slide first, then apply the template. Template-first makes content serve layout; outline-first exposes gaps and evidence.

Revisit this concept

Question 6 · Reference answer

Definitions (deduplication, missing values, time window), row/column orientation, units and totals. Ask it to restate definitions and sample counts before results; recheck key numbers against the sheet.

Revisit this concept

Question 7 · Reference answer

Recipients and cc, commitments/numbers/dates, tone and confidentiality. Especially check whether it made an commitment you were not authorised to make.

Revisit this concept

Question 8 · Reference answer

A list without clause location, conditions and proposed edits cannot support negotiation. Require verbatim clauses, obligations and exit terms, then have legal review.

Revisit this concept

Question 9 · Reference answer

UI, instructions, legal and marketing copy translate; brand names, code, API fields, regulation numbers and trademarks usually stay, unless an official local name exists. Build a glossary first to avoid inconsistent terms.

Revisit this concept

Question 10 · Reference answer

Remove direct identifiers such as names, phones, ID numbers, addresses and accounts; aggregate where possible; keep only fields needed for analysis and record who masked and who can re-identify. Pseudonymising is not deletion.
