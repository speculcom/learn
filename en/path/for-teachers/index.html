The Teacher Route

StarterNo background needed: build the concepts first

about 40 minutes

From “can AI enter the classroom” to lesson prep, question generation, grading and interaction. Every step keeps a teacher checkpoint so model output never goes straight to students.

Read in this order
  1. Generative AI
  2. Hallucination
  3. Prompt
  4. Structured Output
  5. Guardrails
  6. Evaluation Limits
  7. Human Review Queue
  8. How to prepare a lesson with AI
  9. How to generate questions and grade with AI
  10. How to design AI interaction for the classroom
Checkpoint
  1. Explain which AI-generated classroom content can be used directly and which a teacher must verify first
  2. Turn one learning objective into hook, explanation, practice and summary, marking where AI participates
  3. Give students an AI-generated question that may be wrong and have them find and explain the error
  4. Why set “do not ask” boundaries before AI interaction in class?
  5. How do you avoid AI-generated questions that only test recall?
  6. If students use AI for homework, what should assessment look like?
  7. Lesson material contains student data; what is the minimum handling?
  8. When must an AI-graded score be reviewed by a human?
  9. How do you teach labelling and copyright when bringing AI content into class?
  10. How do you write AI use into a lesson’s learning objectives?

Try answering before opening the reference. Revisit the relevant step above if needed. These answers highlight key ideas; you do not need to repeat the wording.

Question 1 · Reference answer

Facts, formulas, dates, worked answers and values judgments need teacher verification; activity ideas, tiered practice and wording variants can be drafted by AI.

Revisit this concept

Question 2 · Reference answer

Write the objective as “what students can do”; each phase gets time, teacher/student actions and a checkpoint; state whether AI generates, probes or gives feedback.

Revisit this concept

Question 3 · Reference answer

The point is not “AI can be wrong” but that students can locate whether the condition, calculation or conclusion failed, and rebut it with the textbook or source.

Revisit this concept

Question 4 · Reference answer

Define what must not go to an external tool (student privacy, exam items, unpublished material) before discussing use. Without boundaries, interaction leaks data before learning effects matter.

Revisit this concept

Question 5 · Reference answer

Ask for new material, explanations, comparisons or error-finding; answers must be rubric-scorable, not just recall. Solve them yourself and delete ambiguous items.

Revisit this concept

Question 6 · Reference answer

Look at process evidence: outlines, revision history, source checks and oral explanation, then the final work. Product-only grading cannot distinguish authorship or teach method.

Question 7 · Reference answer

Remove names and identifying combinations, keep only fields needed for teaching, use masked samples in external tools and confirm retention/deletion. Do not upload the raw class roster.

Revisit this concept

Question 8 · Reference answer

When it affects progression, rewards, subjective items, borderline scores, suspected plagiarism or appeals. Machine scores are a first pass; final scores need an explainable rubric and reviewer.

Revisit this concept

Question 9 · Reference answer

Teach which content must be labelled AI-generated, which assets cannot be used commercially, and that citations must return to the original. Have students check their work with a source/licence/label table.

Revisit this concept

Question 10 · Reference answer

Write observable behaviour: students draft with AI, verify two sources, identify one error and explain why. Avoid unassessable goals such as “can use AI”.
