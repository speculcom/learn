The Half-Hour Primer

StarterNo background needed: build the concepts first

about 30 minutes

Read ten common concepts, then try ten questions. Aim to distinguish models, products and limits without memorizing the whole glossary.

Read in this order
  1. Artificial Intelligence, AI
  2. Machine Learning, ML
  3. Large Language Model, LLM
  4. Prompt
  5. Token
  6. Context Window
  7. Product vs Model
  8. Generative AI
  9. Agent vs Chatbot
  10. Capability Boundary
Checkpoint
  1. Explain to a newcomer how a large model learned, and why billing counts tokens
  2. Tell apart an AI product from an AI model, with one example each
  3. Name at least one thing a large model plainly cannot do
  4. How do machine learning, deep learning and large models relate?
  5. Why do cost and latency usually rise when context grows from 8k to 128k?
  6. What fundamentally differs between generative AI and a classifier?
  7. What is the biggest difference between an AI agent and a chatbot? Give one task for each.
  8. Why is fluent wording not evidence of correctness?
  9. Why can the same prompt produce different outputs twice?
  10. Which three questions should you ask first about an AI product page?

Try answering before opening the reference. Revisit the relevant step above if needed. These answers highlight key ideas; you do not need to repeat the wording.

Question 1 · Reference answer

Training adjusts model parameters from examples; inference generates output from an input. Tokens are text-processing units. Providers commonly count input and output usage separately; the product defines billing.

Revisit this concept

Question 2 · Reference answer

A model generates or processes content. A product also has an interface, retrieval, storage and permissions. A chat website is a product; its language model is one component.

Revisit this concept

Question 3 · Reference answer

Without reliable sources or suitable tools, a model cannot guarantee current facts. Fluent wording does not prove correctness. Give one example that needs an original-source check.

Revisit this concept

Question 4 · Reference answer

Machine learning is the broad approach of learning patterns from data; deep learning uses multilayer neural networks; large models are usually very large Transformer-based deep networks. A large model is not all of machine learning, nor a product.

Revisit this concept

Question 5 · Reference answer

The model processes more tokens, and attention plus cache computation and storage grow with length; the server also reserves more memory and bandwidth. A larger window only means more input fits, not that every position is used equally well.

Revisit this concept

Question 6 · Reference answer

A classifier outputs probabilities over a finite label set; a generative model outputs a distribution over token sequences and samples token by token. The latter can write new content, and brings factual inconsistency and non-reproducibility.

Revisit this concept

Question 7 · Reference answer

A chatbot mainly generates replies; an agent also plans steps, calls tools, reads results and keeps acting. Q&amp;A is chat; checking inventory, editing a ticket or sending mail is an agent task. Tool use and side effects are the dividing line.

Revisit this concept

Question 8 · Reference answer

Fluency only shows the model is good at predicting the next token; it does not guarantee a source for every claim. Check original material, especially numbers, dates, quotations and commitments.

Revisit this concept

Question 9 · Reference answer

Generation usually samples from probabilities; temperature, random seeds and server batching all affect the result, as do model version and context changes. For reproducibility, pin settings and record the version.

Revisit this concept

Question 10 · Reference answer

First, can it cover the task and acceptance criteria; second, where data goes and whether it is retained or transferred; third, total cost, licence and exit. Answer these before judging demos.

Revisit this concept
