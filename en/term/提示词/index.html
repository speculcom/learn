Prompt

Prompt

  • Model capabilities
  • Stage 1 · Getting In
  • refs checked 2026-11-09
What problem it solves

The instructions you give the model, and often the main lever you actually control.

What it is
The input text shaping the model's behaviour. In a chat interface it is what you type; in an API it is part of the request.
Why it matters

For using models, prompt quality often matters more than model choice — the same model behaves very differently under different phrasing.
