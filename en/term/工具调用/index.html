Tool Calling / Function Calling

Tool Calling / Function Calling

  • Agents
  • Stage 3 · Going Deeper
  • refs checked 2026-11-09
What problem it solves

Let the model actually do things — search, run code, edit files — rather than only describe them.

What it is
A mechanism where the model emits a structured request for a function, the system runs it, and the result goes back into the conversation.
Why it matters

It is what turns a language model into a usable assistant. It also introduces real risk: the model can act wrongly, not just speak wrongly.

What to read next, and why
