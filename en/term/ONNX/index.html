ONNX (Open Neural Network Exchange)

ONNX (Open Neural Network Exchange)

  • Hardware & deployment
  • Stage 5 · Running It
  • refs checked 2026-11-17
What problem it solves

Let models trained in different frameworks be exchanged and deployed in one file format.

What it is
ONNX is an open standard for computation graphs, operators and data types; inference engines can load it directly. It does not handle training. It solves the format barrier between one framework’s training and another environment’s inference.
Why it matters

Cross-platform deployment, edge devices and vendor swaps all meet it. Incomplete operator coverage still forces fallbacks or custom ops.
