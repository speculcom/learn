A2A (Agent2Agent Protocol)

A2A (Agent2Agent Protocol)

  • Agents
  • Stage 3 · Going Deeper
  • refs checked 2026-11-17
What problem it solves

Let agents from different vendors and frameworks discover each other’s capabilities, delegate tasks and return results.

What it is
A2A is an open protocol built around an Agent Card (a capability description) and task-lifecycle messages. It adds the agent-to-agent collaboration layer; it does not replace agent-to-tool protocols such as MCP.
Why it matters

In multi-agent deployment the friction is often interoperability, not the model. A2A tries to standardise discovery, authorization and long-running task state.
