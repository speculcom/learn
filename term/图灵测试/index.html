图灵测试Turing Test

Turing Test

  • 核心概念Core concepts
  • 第一段 · 进门Stage 1 · Getting In
  • 引用核验 2026-11-09refs checked 2026-11-09
解决什么问题What problem it solves

1950 年图灵提出的经典问题：聊不出你是机器，算不算机器会思考？Turing's 1950 classic: if conversation can't tell machine from human, does that count as machine thinking?

这是什么What it is

出自图灵 1950 年论文《Computing Machinery and Intelligence》，他原称「模仿游戏」。

玩法：评判者与机器和真人分别对话，分不清哪个是机器，机器即通过。

现代评测普遍不再把它当严格的能力指标。

但它是「AI 能否以假乱真」这一整条讨论的源头。

From Turing's 1950 paper 'Computing Machinery and Intelligence', where he called it the 'imitation game'.

Setup: a judge converses with a machine and a human; if the judge can't tell which is which, the machine passes.

Modern evaluation generally no longer treats it as a rigorous capability measure.

But it is the source of the whole 'can AI pass as real' discussion.
为什么需要知道Why it matters

「通过图灵测试」仍是媒体爱用的说法。知道它 70 多年前就提出、今天已不被专业评测当真，你才对这类标题免疫。'Passed the Turing test' is still a media favorite. Knowing it dates to 1950 and is no longer taken seriously by professional evaluation inoculates you against such headlines.
