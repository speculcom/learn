解决什么问题What problem it solves

知道模型明确做不到什么，比知道它能做什么更能避免踩坑。Knowing precisely what a model cannot do prevents more mistakes than knowing what it can.

这是什么What it is

一个系统在特定输入下可靠产出的范围之外的部分。

The region outside the range in which a system reliably produces correct output for a given input.
为什么需要知道Why it matters

这是使用 AI 的核心素养——把重要任务放在可靠区间内。It is core literacy for using AI — keep important tasks inside the reliable range.
