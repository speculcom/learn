A2A（Agent2Agent 协议）A2A (Agent2Agent Protocol)

A2A (Agent2Agent Protocol)

  • 智能体Agents
  • 第三站 · 用深Station 3 · Going Deeper
  • 引用核验 2026-11-17refs checked 2026-11-17
解决什么问题What problem it solves

让不同厂商、不同框架的智能体互相发现能力、委派任务并回传结果。Let agents from different vendors and frameworks discover each other’s capabilities, delegate tasks and return results.

这是什么What it is

A2A 是开放协议，核心是 Agent Card（能力描述）与任务生命周期消息。

它补的是 agent 之间的协作层，不替代 MCP 这类「agent 接工具」的协议。

A2A is an open protocol built around an Agent Card (a capability description) and task-lifecycle messages.

It adds the agent-to-agent collaboration layer; it does not replace agent-to-tool protocols such as MCP.
为什么需要知道Why it matters

多智能体落地时，最大的摩擦往往不是模型而是互通；A2A 试图把发现、鉴权、长任务状态统一。In multi-agent deployment the friction is often interoperability, not the model. A2A tries to standardise discovery, authorization and long-running task state.
