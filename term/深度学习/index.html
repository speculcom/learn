深度学习

Deep Learning

  • 核心概念Core concepts
  • 第一站 · 进门Station 1 · Getting In
解决什么问题What problem it solves

用很多层「神经元」叠起来的网络，从数据里学出复杂特征。Stack many layers so the network learns its own features instead of being told them.

这是什么What it is

机器学习的一个分支，核心是层数很深的人工神经网络。

「深度」指网络的层数多，不是指它更深奥。

Machine learning using multi-layer neural networks, where representations are learned from raw data rather than hand-designed.
为什么需要知道Why it matters

你现在用的所有大模型都属于这一类。看到这个词就知道：背后是数据 + 算力堆出来的。It is what made image, speech and language tasks leap forward. Understanding it helps you judge which claims about "deep learning" are real.
