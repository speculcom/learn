Looped Transformer（循环 Transformer）Looped Transformer

Looped Transformer

  • 模型能力Model capabilities
  • 第四段 · 看懂Stage 4 · Under the Hood
  • 引用核验 2026-11-23refs checked 2026-11-23
解决什么问题What problem it solves

同一组 Transformer 层被反复调用多次，用循环深度换推理能力，而不是继续堆参数。The same Transformer block is called repeatedly so that looped depth buys reasoning capacity instead of more parameters.

这是什么What it is

标准 Transformer 每一层只过一遍。循环 Transformer 把中间一段层重复执行多次，再回到后续层。

层数 × 循环次数 = 实际展开的层应用数，但权重数量不变。增加的是计算、激活与 KV 缓存。

它和 MoE 不是一回事。MoE 增加的是专家参数与路由，循环增加的是同一组权重的重复计算。

Inkling 2 Mini 是 24 层，6–17 层循环 3 次，共 48 次层应用。26.4B 总参、3.4B 每 token 激活，循环后约 5.4B 有效激活。

A standard Transformer passes each layer once; a looped Transformer repeats a middle block several times before continuing.

layers × loops = the number of layer applications actually unrolled, while the weight count stays fixed; compute, activations and KV cache grow.

It is not MoE: MoE adds expert parameters and routing, while looping repeats the same weights.

Inkling 2 Mini has 24 layers, with layers 6–17 looped three times for 48 layer applications; 26.4B total, 3.4B active per token and about 5.4B effective active after looping.
为什么需要知道Why it matters

2026 年的 Inkling 2 Mini / Small 把循环层用作「不增加参数、但增加推理步骤」的手段。看到「有效激活」这个词时，要知道它把循环计算折算进去了，不是又一个参数口径。循环能加深推理，但不会让模型多记住知识。延迟与 KV 缓存仍随上下文增长。In 2026 the Inkling 2 Mini / Small line uses looping as a way to add reasoning steps without adding parameters. When you see “effective active”, it folds looped compute into the count rather than inventing another parameter metric. Looping deepens reasoning but does not make the model store more knowledge; latency and KV cache still grow with context.
