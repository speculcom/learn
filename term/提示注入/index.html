提示注入Prompt Injection

Prompt Injection

  • 智能体Agents
  • 第三段 · 用深Stage 3 · Going Deeper
  • 引用核验 2026-11-03refs checked 2026-11-03
解决什么问题What problem it solves

外部内容里藏着指令，骗AI 执行你没打算让它做的事。The main security risk in agent systems: content that talks the model into doing something you did not intend.

这是什么What it is

攻击者把指令藏在模型会读取的内容里，比如网页、文档、邮件。模型会把它当成用户指令执行。

这是 Agent 时代最重要的安全风险之一。

An attack where instructions hidden in retrieved documents, tool output or a web page hijack the model's behaviour.
为什么需要知道Why it matters

这解释了为什么让 AI 读网页或邮件有风险。它也解释了权限确认机制为什么必须保留。It is the single most important thing to understand before deploying an agent that reads untrusted content.

    比较可信指令与不可信材料的边界。Distinguish trusted instructions from untrusted material.

  • AI 安全AI Safety

    先看攻击面，再看防护手段：提示注入是 AI 安全里最常被触发的一类。Start with the attack surface: prompt injection is the most frequently triggered risk in AI safety.

  • 插件与 MCP 的信任边界Plugin and MCP Trust Boundary

    注入往往不是靠聊天窗口，而是靠可执行的外部内容生效。Injection usually lands through executable external content, not the chat box.
