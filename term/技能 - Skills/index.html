解决什么问题What problem it solves

把重复的工作流程打包成可复用的能力。Package a repetitive workflow into a reusable capability.

这是什么What it is

把一套提示词、工具配置和执行步骤封装起来，供多次任务调用。

Wrapping a set of prompts, tool configuration and execution steps so they can be called across many tasks.
为什么需要知道Why it matters

这是从「每次重新交代」到「一次配置反复用」的关键机制。It is the mechanism that moves you from re-explaining every time to configuring once and reusing.
